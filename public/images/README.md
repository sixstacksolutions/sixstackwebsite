# Images

Drop real photos here and they appear automatically on the site. Until a file
exists, the card shows the on-brand generated artwork instead (never a broken
image), so you can add photos gradually.

## Where photos go

**Service cards (home page "Our Services"):**
`public/images/services/<service-slug>.jpg`

- `services/web-development.jpg`
- `services/mobile-development.jpg`
- `services/ai-development.jpg`
- `services/backend-development.jpg`
- (optional, used on detail pages later) `services/ui-ux-design.jpg`,
  `services/cloud-devops.jpg`, `services/automation.jpg`,
  `services/cybersecurity.jpg`, `services/software-consulting.jpg`

**Project cards:**
`public/images/projects/<project-slug>.jpg`
(e.g. `projects/northwind-commerce.jpg`)

## Tips

- Landscape photos work best. Aim for ~1200px wide, JPG, under ~300 KB.
- Keep the **exact file names** above (all lowercase, with hyphens).
- After adding files, hard-refresh the browser (Ctrl+Shift+R).
